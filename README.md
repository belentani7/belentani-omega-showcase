# Omega Showcase — Galería de Versiones

Galería navegable de todas las versiones del proyecto web Belentani.

## Qué es

La obra ha tenido muchas versiones. En vez de borrarlas, están todas aquí, navegables y
comparables. Es memoria técnica y también memoria artística.

En línea: <https://belentani7.github.io/belentani-omega-showcase/>

## Estructura

```
immersive-portal/    version del portal inmersivo
nexus-void-mirror/   version Nexus
omega-live/          version en vivo
omega-live-baseline/ linea base
mockups/             maquetas
index.html           galeria
```

## Cómo se usa

Se entra por la galería y se navega versión a versión. Cada carpeta es un estado congelado:
no se editan, se conservan.
